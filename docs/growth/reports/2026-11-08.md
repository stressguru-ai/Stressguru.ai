## Narrow source corrections

The existing source publication guard matched only raw `/blogs/<slug>` URL spellings, while file serving decoded and normalized equivalent paths. A local fixture with a synthetic unpublished resolver demonstrated that encoded, repeated-slash, and dot-segment variants could return a snapshot without checking publication. The guard now identifies the same logical blog slug and checks publication before redirects or file serving. Published articles remain available, unpublished ones remain 404, and lookup failures remain 503 with retry guidance. Tests also retain a same-origin canonical redirect for repeated leading slashes. This reproduction does not establish that a live unpublished article was exposed.

The raw-HTML inspector also crashed on valid JSON syntax containing invalid structured-data node shapes, such as `null` or an array with a null entry. It now records a structured-data shape finding without discarding the route’s status, title, canonical, and other evidence. Valid graph objects, arrays, and multiple schema types remain supported. This changes the audit, not public schema or article content.
